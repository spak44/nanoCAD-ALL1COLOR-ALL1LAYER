# LISP-команды для nanoCAD

Команды для изменения свойств выделенных объектов и содержимого блоков без их разрушения.

| Файл | Команда | Версия | Назначение |
|---|---|---|---|
| [ALL1LAYER.lsp](ALL1LAYER.lsp) | `ALL1LAYER` | 1.1 | Перенос выделенного и содержимого блоков на один слой |
| [ALL1COLOR.lsp](ALL1COLOR.lsp) | `ALL1COLOR` | 1.0 | Назначение одного цвета выделенному и содержимому блоков |
| [ALL1PROP.lsp](ALL1PROP.lsp) | `ALL1PROP`, `ALL1TRANS`, `ALL1WEIGHT`, `ALL1LTYPE` | 1.0 | Несколько свойств за проход или отдельные команды |

## Загрузка

1. Скачайте репозиторий: **Code → Download ZIP**, распакуйте архив.
2. В nanoCAD выполните `APPLOAD`.
3. Выберите нужный `.lsp` и нажмите «Загрузить».
4. Введите имя команды в командной строке.

Скрипты используют Visual LISP/ActiveX в Windows. Требуется соответствующая поддержка в вашей редакции nanoCAD. Совместимость со всеми версиями не проверена. Перед первым запуском сохраните копию DWG.

## ALL1LAYER — один слой

1. Введите `ALL1LAYER`.
2. Выделите объекты и блоки, нажмите Enter. Можно выделить объекты до запуска команды.
3. Выберите объект на слое назначения или нажмите Enter для текущего слоя.

Команда обходит вложенные блоки и атрибуты. Цвет, тип и толщина линий отдельно не меняются. При цвете «По слою» отображение может измениться вслед за слоем.

## ALL1COLOR — один цвет

1. Введите `ALL1COLOR`.
2. Выделите объекты и блоки, нажмите Enter. Предварительное выделение также поддерживается.
3. Введите номер цвета либо нажмите Enter для выбора объекта-образца.
4. При выборе образца щёлкните по нужному элементу, в том числе внутри блока. Повторный Enter назначает «По слою».

| Номер | Цвет / режим |
|---|---|
| 1 | Красный |
| 2 | Жёлтый |
| 3 | Зелёный |
| 4 | Голубой |
| 5 | Синий |
| 6 | Фиолетовый |
| 7 | Белый / чёрный в зависимости от фона |
| 8–255 | Остальные индексированные цвета |
| 0 | По блоку |
| 256 | По слою |

С образца копируется назначенное свойство цвета, включая TrueColor. Если у образца «По слою» или «По блоку», копируется этот режим, а не видимый цвет. Чтобы получить одинаковый явный цвет на разных слоях, используйте номер 1–255 или образец с явно заданным цветом.

## ALL1PROP — несколько свойств за один проход

Загрузите [ALL1PROP.lsp](ALL1PROP.lsp) через `APPLOAD`. Этот файл добавляет четыре команды:

| Команда | Что изменяет |
|---|---|
| `ALL1PROP` | Слой, цвет, прозрачность, тип линий, вес линий и масштаб типа линий |
| `ALL1TRANS` | Только прозрачность |
| `ALL1WEIGHT` | Только вес (толщину отображения) линий |
| `ALL1LTYPE` | Только тип линий |

Выделите объекты и запустите команду либо выберите объекты по её запросу. **Enter в запросе свойства означает «не менять»**. Изменения применяются после выбора всех параметров. Если все параметры пропущены, DWG не изменяется.

Параметры `ALL1PROP` запрашиваются последовательно:

1. **Layer** — `Name`: имя существующего слоя; `Sample`: объект на нужном слое. Слой назначения должен быть разблокирован.
2. **Color** — `Number`: номер 1–255, 0 = «По блоку», 256 = «По слою»; `Sample`: цвет объекта-образца, в том числе вложенного.
3. **Transparency** — `Value`: число от 0 до 100 (0 — непрозрачный, 100 — невидимый); `Layer` — «По слою»; `Block` — «По блоку».
4. **Linetype** — `Name`: имя загруженного типа; `Sample`: тип объекта-образца; `Layer`: «По слою»; `Block`: «По блоку»; `Continuous`: сплошная линия. Если нужный тип отсутствует, загрузите его через `LINETYPE` перед запуском.
5. **Lineweight** — `Value`: стандартное значение в мм, например `0.25`, `0.35`, `0.50`; `Layer`: «По слою»; `Block`: «По блоку»; `Default`: стандартный вес. Используйте точку для дробного значения.
6. **LINETYPE scale** — положительный масштаб типа линий, например `1`, `10` или `100`. Размеры геометрии, масштабы вставок блоков, аннотативные масштабы и глобальный `LTSCALE` не изменяются.

**Вес линий — это свойство «Вес линий», а не геометрическая ширина полилинии.** Для отображения весов линий включите кнопку «ВЕС» в строке состояния.

В `ALL1TRANS`, `ALL1WEIGHT`, `ALL1LTYPE` выводится только запрос соответствующего свойства.

Наследуемые свойства «По слою» и «По блоку» не гарантируют одинаковый вид на разных слоях или в разных вставках. С образца копируется назначенное свойство.

Обрабатываются выделенные объекты, определения обычных и вложенных блоков, атрибуты обработанных вставок. Динамические блоки обрабатываются по доступным определениям; сохранение результата при дальнейших изменениях параметров таких блоков требует проверки в вашей версии nanoCAD. Содержимое общих определений изменяется во всех вставках. Заблокированные сущности пропускаются; вставка на заблокированном слое не делает её общее определение отдельным или защищённым от изменений через другие вставки.

В конце выводятся `Processed`, `Failed`, `Locked` и число пропущенных определений внешних ссылок. `Processed` считает успешные операции назначения; отдельные атрибуты могут обрабатываться повторно. Применённые изменения объединяются в одну операцию отмены. Слой и все невыбранные свойства сохраняются; изменение слоя может косвенно изменить свойства «По слою».

### Пример: всё серое, прозрачность 50%, вес 0.13 мм

Запустите `ALL1PROP`, выберите объекты, затем:

- Layer: **Enter**.
- Color: **Number**, затем **8**.
- Transparency: **Value**, затем **50**.
- Linetype: **Enter**.
- Lineweight: **Value**, затем **0.13**.
- LINETYPE scale: **Enter**.

### Если вместо заливки виден контур

Выполните `FILLMODE` → `1`, затем `REGEN`. Это настройка отображения заливок и штриховок, общая команда свойств её не переключает.

## Особенности

- Блоки сохраняются, включая вложенные блоки.
- Определения блоков общие: изменение содержимого затрагивает все вставки того же блока в DWG, включая невыделенные. Атрибуты отдельных невыделенных вставок отдельно не обходятся.
- Содержимое внешних ссылок пропускается; свойство самой выбранной вставки может измениться.
- Заблокированные слои автоматически не разблокируются. Возможны отказы изменения отдельных объектов; смотрите счётчик `Failed`.
- Внутренние цветовые коды фрагментов МТЕКСТа и отдельные переопределения размеров не очищаются.
- При успешном завершении изменения объединяются в одну операцию отмены (`U` / Ctrl+Z).
- В конце выводятся количество обработанных объектов, отказов и пропущенных определений внешних ссылок.
- После ошибки часть изменений может сохраниться: отмените операцию или вернитесь к копии DWG.

## Проверка

Выполнена статическая проверка структуры LISP. Полноценные испытания команд в nanoCAD не завершены; скрипты не заявлены как проверенные для всех редакций и типов объектов.

## Изменения

- **ALL1PROP 1.0:** слой, цвет, прозрачность, тип и вес линий, масштаб типа линий; отдельные команды ALL1TRANS, ALL1WEIGHT, ALL1LTYPE. Enter сохраняет исходное свойство. Изменение DXF ограничено общими свойствами сущности, геометрия и XDATA сохраняются.

- **ALL1LAYER 1.1:** атрибуты обходятся напрямую через сущности ATTRIB, без COM-массива GetAttributes; исправлен участок, вызывавший ошибку `variant 8204`.
- **ALL1COLOR 1.0:** добавлено рекурсивное назначение цвета, выбор номера и копирование цвета с образца.
